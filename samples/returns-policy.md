# Demonstration returns policy

This fictional policy is separate from the inventory-transfer policy so that
semantic retrieval can be demonstrated across different documents.

Inspect returned goods before making them available for fulfillment. Record the
inspection outcome and quarantine damaged goods. Returned items must not be
counted as transferable inventory until inspection has passed.

When asked for a return authorization number or an actual customer's order,
this policy does not supply those facts. Query the authorized transactional
system instead; do not invent an identifier.
